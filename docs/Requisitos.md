Seis requisitos Mínimos 


ID	Requisito

RF01	O sistema deve permitir a pesquisa de  produtos e apresentar um estado de busca que seja compreensível ao usuário.
RF02	O sistema deve permitir consultar os detalhes dos produtos e adicionar ao carrinho a oferta selecionada.
RF03	O sistema deve permitir que seja alterado a quantidade e remover itens, respeitando os limites apresentados na interface.
RF04	O sistema deve calcular o subtotal dos itens selecionados e preservar o estado do carrinho após atualizar a página na mesma sessão.
RF05	O sistema deve exigir a autenticação antes do acesso às etapas pessoais do checkout.
RF06	O sistema deve validar dados obrigatórios de entrega e apresentar informações consistentes (referentes ao produto) nas etapas acessíveis do checkout.
